HidenCloud 自动续费脚本，支持多账号、TG 通知、Cookie 自动更新。

## 核心功能
- **自动续期**：默认续期 7 天。
- **自动扣费**：检测到未支付订单时自动用账户余额支付。
- **TG 推送**：包含账号、余额、执行结果及每日一言。
- **持久化**：配合 GitHub PAT 可自动回写 Cookie，不用频繁手动更新 Secret。
